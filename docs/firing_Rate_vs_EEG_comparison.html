Cortical Firing Rate 和 EEG 电压的比较

Cortical firing rate 不是 EEG 电压，但在慢振荡形状比较里，可以把它当作 “皮层活动强弱随时间变化的 proxy”。比较时不要比绝对单位和绝对振幅，而是比低频节律的时间结构： 峰谷位置、周期、波形宽窄、上升和下降形状。

一、相似和区别

维度 Cortical firing rate EEG 电压 相似之处 比较时要注意
物理含义 模型里皮层兴奋性群体的平均放电率 头皮电极测到的电位差 都反映皮层神经群体活动随时间变化 不是同一种物理量，不能直接比数值大小
单位 通常是 Hz 或 spikes per second 微伏，记作 uV 都可以看成一条时间序列 单位完全不同，必须标准化
来源 neurolib neural mass model 的状态变量 真实脑电仪记录 都可表现 N3 慢振荡 firing rate 是模型内部变量，EEG 是经过组织、头骨、电极混合后的外部观测
空间尺度 一个模型节点或神经群体的平均活动 电极附近大量神经源的混合投影 都属于群体级信号，不是单神经元信号 EEG 更受 volume conduction、电极位置和参考电极影响
慢振荡表现 UP/DOWN 状态导致 firing rate 高低交替 N3 中出现大幅低频慢波 二者都能有 0.3-1.5 Hz 的周期结构 极性可能相反：模型 peak 不一定对应 EEG peak
振幅意义 放电率高低，反映神经群体激活程度 电位差大小，受源强度和传导影响 振幅变化都可表示活动强弱变化 不应直接比较“多少 Hz”和“多少 uV”
频谱 可计算 PSD、SO band power、sigma band power 也可计算 PSD、频段功率 都能做滤波和频谱分析 模型信号可能比 EEG 更干净，真实 EEG 有噪声和伪迹
波形形状 可能更尖、更规则、机制驱动更强 可能更平滑、更混合、有噪声 可比较归一化后的周期平均形状 需要滤波、对齐、归一化后比较
生理解释 表示“模型皮层节点活动如何变化” 表示“头皮上观测到的电场变化” 二者都和皮层同步活动有关 EEG 不是 firing rate 的线性复制品
适合比较什么 周期、峰谷结构、UP/DOWN timing、相对形状 周期、峰谷结构、慢波模板、spindle 可见性 适合比较 rhythm morphology 不适合直接说模型生成了真实 EEG 电压

二、如何比较二者的“形状”

在 valid_scripts/validate_so_waveform_heldout.py 里，比较的不是原始数值，而是慢振荡频段里的平均周期形状。 这可以分成四步理解。

  1. 只看同一个频段。 真实 EEG 和 cortical firing rate 都先滤到 SO 频段 0.3-1.5 Hz。 这样比较的是慢振荡形状，而不是全部信号。
  2. 去掉单位差异。 EEG 是 uV，firing rate 是类似 Hz 的量，所以不能直接比较振幅。 脚本用 z-score 标准化： 标准化后 = (信号 - 平均值) / 标准差。 这样每条信号都变成“相对高低变化”，不再关心原始单位。
  3. 按 SO 周期对齐。 脚本找每个慢波的 peak 或 trough，然后在锚点前后各取 1 s。 这相当于把很多个慢波周期剪成一张张小卡片，并把峰或谷对齐在中间。
  4. 平均成模板再比较。 把所有 SO snippets 平均，得到一个代表性慢波模板。 然后比较模型模板和真实 EEG 模板的 RMSE 和 correlation。

三、两个指标怎么读

  • RMSE：两条模板平均差多少。越小，说明形状越接近。
  • Correlation：两条模板走势是否一致。越接近 1，说明上升、下降、峰谷结构越一致。

所以这里的“相似”不是指模型 firing rate 的数值等于 EEG 微伏值，而是指： 在慢振荡频段里，模型的上升、下降、峰谷位置、周期平均轮廓，和真实 EEG 的周期平均轮廓是否相似。

直观比喻： EEG 电压和 firing rate 像两种不同乐器。EEG 是钢琴录音，firing rate 是小提琴旋律线。 它们音色和响度不同，不能直接比“声音大小”。但如果都在演同一首慢节奏旋律，就可以比较节拍是否一致、 高低起伏是否类似、每个音符出现的时间是否接近、平均旋律轮廓是否相似。 这个脚本比较的就是“旋律轮廓”，不是“音色”和“音量”。
