Figure-10-inspired Validation Panel：看图说话说明

项目：personalized thalamocortical sleep neural mass fitting ｜ 日期：2026-07-13 ｜ 生成脚本： valid_scripts/plot_figure10_inspired_validation_panel.py
先定调：这张图是受 SBI Figure 10 启发的 validation / audit panel，但当前项目还没有 q_phi(theta|x) 形式的 posterior estimator。因此这里不能叫 posterior samples，也不能声称做了 expected coverage、SBC、TARP 或 L-C2ST。 本图展示的是 fitted-candidate ensemble 上的 PPC-like predictive diagnostics 和一个 cheap synthetic parameter-recovery diagnostic。
主图位置：outputs/figure10_inspired_validation_panel/figure10_inspired_validation_panel.png。 同目录下也保存了 PDF、candidate archive、predictive summaries、real observation summaries 和 synthetic recovery 结果。

这张图到底在验证什么？

这张图的核心问题不是“我们是否已经有一个校准良好的 posterior”，而是： 在现有 V1-V8/V8a 拟合历史和诊断搜索中，已经留下了一批候选参数。我们能不能把这些候选组织成一个 candidate archive，然后用统一的短仿真和统一 summary metrics 检查它们是否能生成类似真实 N3 EEG 的关键现象？

所以它做的是三层 validation：

  • 候选空间验证：现有候选是否覆盖了不同版本和关键耦合参数区域。
  • 预测行为验证：这些候选短仿真后，是否能覆盖真实 EEG 或审计目标关心的 summary statistics。
  • 可恢复性诊断：如果从某个已知候选生成 synthetic observation，用 archive 最近邻能否找回相近参数。

Panel A：模型和参数空间

Panel A 是文字 schematic。它告诉读者，这不是一个黑箱统计模型，而是一个 8 参数 cortical-thalamic neural mass model。 被统一比较的参数是： 

mue, mui, b, tauA, g_LK, g_h, c_th2ctx, c_ctx2th

这一步的 validation 作用是限定“我们到底在验证哪个模型族”。后续所有 candidate archive、short simulations 和 recovery diagnostic 都在这个 8 参数空间内进行。

Panel B：真实 EEG 的观测摘要

Panel B 把真实 SC4001 N3 EEG 压缩成几个 summary。这里有 PSD 的低频和 sigma band 摘要，以及独立 sigma-RMS detector 得到的 held-out spindle density。

看图重点：真实 EEG 不是拿整条时间序列直接和模型逐点比较，而是先抽取和科学问题相关的 summary： slow oscillation / spectral shape / spindle density / PAC-like metrics。这样后续 candidate simulation 才能在同一组 summary 上比较。

当前脚本中，如果某些真实 EEG summary 没有现成 utility，例如 PAC preferred phase 或 SO morphology 的完整真实 EEG版本， 就填成 NaN 并在 summary 中说明，不让脚本失败。这是保守做法。

Panel C：fitted-candidate ensemble

Panel C 是参数空间散点图：横轴 c_th2ctx，纵轴 c_ctx2th，颜色表示版本或来源。 这张图回答的问题是：我们现在手里的 candidate archive 覆盖了哪些耦合区域？

这里的 archive 来自三类来源：

  • V1-V8 的 best JSON candidate。
  • V3-V8 的 evolution records top candidates。
  • V8a relaxed / coupling / ultra / local diagnostic CSV 中的候选。

脚本保证 best JSON candidate 优先保留，再从 records 和 diagnostics 中按 n_passed、score 以及 c_th2ctx 多样性补足到 50 个候选。

不能过度解读：这些点不是 posterior samples。它们是历史优化和诊断搜索留下的 fitted-candidate ensemble。 点的密度不能解释成 posterior probability density。

Panel D：PPC-like predictive diagnostics

Panel D 是这张图最接近“predictive check”的部分。它把每个 candidate 做 3 次 60s 短仿真，计算同一批 summary：

  • T6_ibi_cv：SO regularity。
  • T13_ctx_verified_density_per_min：V8a 内部 cortical spindle observability。
  • heldout_rms_spindle_density：独立 sigma-RMS detector 下的 cortical spindle density。
  • T4_q：cortical SO spectral structure。

图中用 box/strip 的方式展示 candidate-generated summary distributions，并画出关键参考线，例如 strict T6 threshold 0.40 和真实 EEG 的 RMS spindle density。

这一步能说明什么：如果真实 EEG summary 落在 candidate ensemble 生成分布附近，说明 archive 里至少存在能近似该 summary 的候选； 如果真实 EEG summary 明显落在分布外，说明当前候选集或模型结构在该观测特征上还有 mismatch。
这一步不能说明什么：它不是严格 posterior predictive check，因为没有 posterior estimator，也没有从 posterior 中采样。 所以文档和图里统一叫 PPC-like predictive diagnostics。

Panel E：synthetic parameter-recovery diagnostic

Panel E 做的是一个便宜的 synthetic recovery 检查。流程是：

  1. 从 archive 中选 5 个 diverse synthetic ground-truth candidates。
  2. 用每个 theta_true 生成一次 synthetic observation summary。
  3. 在 archive 已有 summary 表里做 normalized Euclidean nearest-neighbor search。
  4. 把最近邻 candidate 当作 theta_recovered，计算参数误差。
Synthetic ID True version Recovered version Same version Mean relative error
synth_00 V1 V3 0 0.9538
synth_01 V7 V7 1 0.0682
synth_02 V8a V8a-coupling 0 0.2370
synth_03 V8a-relaxed V8a-coupling 0 0.0682
synth_04 V3 V3 1 0.0000

这里可以看到，V7 和 V3 synthetic cases 能被 archive 最近邻恢复到同版本；V8a-relaxed 被恢复到 V8a-coupling，说明在当前 summary 空间下它们非常接近；V1 恢复较差，说明 V1 的 summary-to-parameter 映射在当前 archive 中不够稳定或不够可辨识。

关键边界：这不是 SBC。SBC 需要从 prior 采样参数、模拟观测、通过 posterior estimator 得到 posterior，再检查 rank statistics。 这里没有 posterior estimator，因此只能叫 synthetic parameter-recovery diagnostic，或者 SBC-inspired but not SBC。

Panel F：future SBI diagnostics box

Panel F 是整张图的“防误读”面板。它明确说：如果未来要做真正 SBI validation，需要训练 q_phi(theta|x)，例如 NPE/NLE/NRE posterior estimator。只有有了这个 posterior estimator，才可以严肃地做：

  • posterior predictive checks；
  • expected coverage；
  • SBC；
  • TARP；
  • L-C2ST 等 local posterior diagnostics。

这个 panel 的作用是把当前图和未来真正 SBI 图清楚地区分开：当前是 candidate archive validation，未来才是 posterior diagnostics。

一句话总结

这张 Figure-10-inspired validation panel 的意义是：把 V1-V8/V8a 历史拟合候选整理成一个 fitted-candidate ensemble， 用真实 EEG summary、短仿真 predictive summaries 和 archive-based synthetic recovery 来做审计式 validation。 它能帮助我们看清当前模型和候选集在哪些 summary 上接近真实数据、在哪些 summary 上仍有 mismatch；但它不是 posterior calibration， 也不能替代未来基于 q_phi(theta|x) 的 SBI diagnostics。
